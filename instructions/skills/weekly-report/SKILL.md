# Weekly report

1. Use the requested window or the previous seven days.
2. Pull only authorized non-private sources: relevant team channels, completed and active issues, merged PRs and main-branch commits, active project pages, and, when available and requested, calendar focus time and usage costs.
3. Link source items and distinguish measured values from missing data.
4. Produce:
   - top five completed outcomes;
   - in-progress work with current state;
   - blockers with owner and age;
   - measured delivery metrics;
   - top three priorities for next week;
   - one or two durable lessons.
5. Do not read private/direct messages. Filter out irrelevant experiments and work outside the requested team scope.
6. Write or send the report to an external destination only when explicitly requested.
