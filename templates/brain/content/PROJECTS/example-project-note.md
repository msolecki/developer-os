Use a project note for work that will one day be done: a migration, a launch, a
piece of research with a question at the end of it.

When the project ends, the durable part usually wants to become a knowledge
note, and the project note itself can move to `_graveyard/` — which is never
indexed, so retired work stops turning up in search without being deleted.
