Running in about five minutes.

  1. Install the plugin in Claude Code

    /plugin marketplace add msolecki/developer-os
/plugin install developer-os@developer-os

    An install takes the latest release, from main; claude plugin update developer-os@developer-os picks up later ones. Auto-update is off unless you turn it on under /plugin.

  2. Set up the vault

    Ask Claude Code to run brain-setup. After you approve the diff it adds a Brain vault: /path/to/vault line to ~/.claude/CLAUDE.md and the vault path to permissions.additionalDirectories, and asks separately whether to turn Claude Code's auto memory off ("autoMemoryEnabled": false, recommended). If you have auto memory already, brain-import-memory moves it into the vault.

  3. Open the vault in Obsidian

    Open the vault folder with “Open folder as vault” (Obsidian 1.9.10 or later). Then Settings, Core plugins: Bases and Templates, with the Templates folder set to templates.

  4. Try it

    Start a session and ask: brain-search webhooks. It should find the example note in the inbox.

For each project, copy templates/project/ into its root; the install keeps a copy on disk, and -n skips files the project already has:

cp -Rn ~/.claude/plugins/marketplaces/developer-os/templates/project/. /path/to/project/

Before you install

Does it send my code or notes anywhere?

The plugin sends nothing by itself and its hooks make no network calls. What the agent reads from the vault goes to your model provider as part of the session, like any file it reads. brain-capture redacts secrets before writing; review inbox notes for client names and personal data before you promote them. Privacy

Does it change how Claude behaves in all my projects?

Yes. The core rules load into every session in every project. Override a rule in your ~/.claude/CLAUDE.md, or disable the plugin under /plugin.

Can I use it without a vault?

Yes. The engineering and session skills, the agents and the hooks work on their own. The brain skills ask once for the vault path and stop if you have none, and the core rules run brain-search only when a vault is configured (the brain_vault option or a Brain vault: line).

Can a hook block a command?

No. The guard only asks, and on input it cannot parse it stays silent. In headless claude -p there is no one to ask, so an ask resolves to a denial.

How much context does it cost per session?

The core rules are capped at 8900 bytes and all skill descriptions at 12000 characters in total; scripts/check.sh fails a change that grows past either. Skill bodies load only when a skill runs.

Is it stable?

It is at release 0.2.9: installs follow main, which moves only on a tagged release. The changelog lists every change.

Which language does it use?

Skills, rules and documentation are in English, and skill descriptions carry English trigger phrasings; conventions skills load by the files you work on. The core rules keep the conversation in your language, whatever it is, and keep everything written to a repository in English unless the project says otherwise.
