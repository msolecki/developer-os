developer-os — documentation index

Source: docs/index.mdVerified 2026-10-15

developer-os is a Markdown-only Claude Code plugin. These documents describe the plugin as it is in this repository; they replace the documentation of the earlier CLI product, which was removed on 2026-10-14 (history at the git tag archive/cli-v0).

Each row routes a task to the one document to read first. Documents link to the source file that owns a behavior (a SKILL.md, a hook script, scripts/check.sh) instead of restating it; when a document and the source disagree, the source wins and the document is a defect.

Outside docs/: README (install, component list), CONTRIBUTING, SECURITY, CHANGELOG, evals/README.md.

Document rules

  • Technical documentation is in English. Every document under docs/ starts with the frontmatter above: status (current, draft or deprecated), owner, and last-verified, the day it was checked against the code.
  • Cite files and section headings, not line numbers; line numbers move with every edit.
  • Plans live in docs/plans/, which is git-ignored, and are deleted when the task is done.
  • scripts/check.sh enforces this frontmatter, and checks every relative link in these files and every developer-os:<name> reference, so a renamed skill or moved file fails the check.
