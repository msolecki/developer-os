Configuration reference

Source: docs/reference/configuration.mdVerified 2026-10-16

The plugin has no configuration file of its own. It is configured through lines and keys in files the user already has, which the skills read. This page lists every one of them.

Codex

No manifest. scripts/install-codex.sh (run by hand, --dry-run first) writes a Codex copy of each skill to ${CODEX_SKILLS_DIR:-~/.agents/skills} with a .developer-os-codex marker, and puts the core rules and the Brain vault: line between developer-os-core markers in ${CODEX_HOME:-~/.codex}/AGENTS.md (README).
