Configuration reference

Source: docs/reference/configuration.mdVerified 2026-10-16

The plugin has no configuration file of its own. It is configured through lines and keys in files the user already has, which the skills read. This page lists every one of them.

User level

Brain vault: <absolute path>~/.claude/CLAUDE.md (or a project's CLAUDE.md/AGENTS.md)All brain skills; the core rule that runs brain-search before large tasks; the notices hook, from the user-level file onlybrain-setup, after approval

Rule overrides~/.claude/CLAUDE.mdThe model, alongside the core rulesThe user
DEVELOPER_OS_CAPTURE_NUDGE, DEVELOPER_OS_CAPTURE_NUDGE_MINShell environmentThe Stop hook (hooks.md)The user
DEVELOPER_OS_NOTICESShell environmentThe SessionStart notices hook; off disables the version and upkeep notices (hooks.md)The user

brain-setup and the brain skills' vault lookup resolve the config directory as ${CLAUDE_CONFIG_DIR:-$HOME/.claude}; brain-setup edits files in place, so symlinked config files stay symlinks.
