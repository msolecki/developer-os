Works

  • Release 0.1.0, tagged v0.1.0. Install from the marketplace on main, which moves only on a release (D20): .claude-plugin/marketplace.json → plugin/.
  • 28 skills, 6 agents, 4 output styles, 3 hooks, as listed in product/functional-spec.md.
  • Per-session cost: core rules 8144 of 8192 bytes; skill descriptions 10065 of 12000 characters; a state card of at most 1024 bytes after compaction or resume.
  • The Codex installer fits all 28 skills in 7500 bytes of descriptions, within Codex's 8000-character budget (it counts bytes, which are never fewer than characters).
  • The shared "Locate the vault" paragraph is identical in brain-capture, brain-compile, brain-garden, brain-review and brain-search; the Vault paragraph stage of scripts/check.sh fails when the first paragraph under ## 1. Locate the vault differs between them.

  • 34 eval cases with a baseline arm, run by hand.
