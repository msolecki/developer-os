# Onboard a client

Prepare a checklist with `done`, `waiting`, or `blocked` status and a named owner for each item.

## Prerequisites

- Confirmed commercial prerequisites (agreement, NDA, payment terms as applicable).
- Client record in the team's CRM or tracker, if used, and a communication channel.
- No outbound messages, purchases, invitations, or account creation without explicit authorization.

## Discovery

- Kickoff agenda and notes.
- Client contacts and responsibilities.
- Required technical access using least privilege.
- Three to five measurable business goals and success metrics.
- Constraints: budget, timeline, technology, compliance, and decision process.

## Setup

- Delivery project and repository naming.
- A durable client workspace (plan, decisions, notes, resources) in the team's tool of choice.
- Communication channels, update format, escalation path, and recurring meeting slot.
- Now/Next/Later roadmap, first milestone, demo, and feedback loop.

## Output

Return the checklist, missing information, risks, and today's next actions. Draft kickoff communication only if requested; never send it automatically.
